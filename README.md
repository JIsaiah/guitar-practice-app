# suguhiku v1.0（ギター練習アプリ）

開いて、弾くだけ。ギターの練習に必要なもの（音源・タブ譜・音色・メトロノーム・チューナー）を
1つの画面にまとめ、曲ごとの「セッション」として保存できるアプリです。練習のたびに、音作りのソフト・YouTube・タブ譜ソフトを行き来し、設定に時間を取られることが無くなります。

**考えずに、すぐ弾き始められる練習環境**を目指しています。片手での操作が容易であることもポイントです。セッション作成後、練習中での操作は文字入力を必要とせず、ギターを持ったままマウスのみで操作でいるように設計しました。

既存コンテンツの利用。練習したい曲があれば、ネット上にあるタブ譜・.gpファイルとお持ちの音源ファイルまたはYouTubeのリンクを貼り付けるだけで練習できます。音色はVSTプラグインを使い、好きなものを選べます。（v1.0では内臓プリセットはクリーンしか対応していません。歪みを実装する予定です）

## ダウンロード

[**Releases**](https://github.com/JIsaiah/guitar-practice-app/releases/latest) から `suguhiku-v1.0.0-windows-x64.zip` をダウンロードしてください。

> 緑の「Code」ボタンの「Download ZIP」では、アプリ（suguhiku.exe）はダウンロードできません。Releases からダウンロードしてください。

## 動かすのに必要なもの

- Windows 10 / 11（64 ビット）
- Microsoft Edge WebView2 ランタイム
  - Windows 11 には最初から入っています。Windows 10 でも、たいていは Edge と一緒に入っています。
  - タブ譜や YouTube が表示されないときは、[こちらのページ](https://developer.microsoft.com/microsoft-edge/webview2/)から「エバーグリーン ブートストラップ」を入れてください。
- ギターの音を出すには、オーディオインターフェース（ギターを挿す機器）
  - 無くても、音源の再生・タブ譜・メトロノームは使えます。

## インストール

1. ダウンロードした zip ファイルを右クリックし、「すべて展開」を選びます
2. 展開したフォルダを、好きな場所に置きます（例: ドキュメントやデスクトップ）
3. フォルダの中の「suguhiku.exe」をダブルクリックすると起動します
   - よく使う場合は、suguhiku.exe を右クリック →「スタートにピン留めする」などが便利です

> 初めて起動すると、「Windows によって PC が保護されました」と出ることがあります。
> 個人で作ったアプリで、電子署名が付いていないためです。
> 「詳細情報」を押し、「実行」を押すと起動します。

## 最初に1回: オーディオの設定

1. 一覧画面の右上の歯車（設定）を押します
2. いちばん下の「オーディオの入出力」で、お使いのオーディオインターフェースを選びます
   - 「Audio device type」で「ASIO」を選ぶと、ギターの音の遅れが小さくなります
   - 入力は、ギターを挿した入力だけを有効にしてください
3. 設定は自動で保存され、次から同じ設定で起動します

## 主要機能

1. **埋め込みブラウザ**<br>
   YouTubeなどのWeb音源を、アプリから離れずに再生できます。音源ファイル持っていなくてもネットにあるものを使って練習ができます。

2. **ラジアルメニュー**<br>
   片手で操作しやすくするように、マウスの両ボタンを長押しすると、曲の再生、ギターのミュート、トラックの切り替えなどのような操作ができます。(v1.0では固定の操作しか行えませんが、できる操作を入れ替える機能を実装する予定です)

3. **音源・楽譜の音をずらす**<br>
   ネットで拾った音源が楽譜に合わない時にどちらかの再生開始時間を調整し、合わせられるようにします。

## 使い方（かんたんに）

1. 一覧画面の「＋」から、新しいセッションを作ります（必要なのは曲名だけです）
2. 練習画面で、音源（音楽ファイル または YouTube の URL）とタブ譜（Guitar Pro・MusicXML）を選びます
3. 「▶」で再生します。速度・ループ・メトロノーム・音色は、保存すると次回もそのまま戻ります

2回目からは、一覧で曲を選んで開き、「▶」を押すだけで練習を再開できます。

## データの保存場所

| 内容                     | 場所                                                                                          |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| セッション・セットリスト | `ドキュメント\GuitarPractice`                                                                 |
| 設定・動作の記録         | `%APPDATA%\GuitarPractice`（エクスプローラーのアドレス欄に `%APPDATA%` と入力すると開けます） |

## アンインストール

展開したフォルダを削除してください。
保存したセッションや設定も消したいときは、上の「データの保存場所」の2つのフォルダも削除してください。

## ご意見・不具合の報告

設定画面のいちばん上の「フィードバックを送る」ボタンから、フォームを開けます。
不具合のときは、設定の「動作ログ・クラッシュの記録を見る…」の内容を添えていただけると助かります。
