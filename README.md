# suguhiku v1.1（ギター練習アプリ）

開いて、弾くだけ。ギターの練習に必要なもの（音源・タブ譜・音色・メトロノーム・チューナー）を
1つの画面にまとめ、曲ごとの「セッション」として保存できるアプリです。練習のたびに、音作りのソフト・YouTube・タブ譜ソフトを行き来し、設定に時間を取られることが無くなります。

**考えずに、すぐ弾き始められる練習環境**を目指しています。片手での操作が容易であることもポイントです。セッション作成後、練習中での操作は文字入力を必要とせず、ギターを持ったままマウスのみで操作でいるように設計しました。

既存コンテンツの利用。練習したい曲があれば、ネット上にあるタブ譜・.gpファイルとお持ちの音源ファイルまたはYouTubeのリンクを貼り付けるだけで練習できます。音色はVSTプラグインを使い、好きなものを選べます。

初心者がギターを弾けるように教えるアプリではありません。本アプリを利用するのにある程度のギターとパソコンの知識が必要です。練習環境を提供しているのみです。

## ダウンロード

[**Releases**](https://github.com/JIsaiah/guitar-practice-app/releases/latest) から `suguhiku-v1.1.1-windows-x64.zip` をダウンロードしてください。

> 緑の「Code」ボタンの「Download ZIP」では、アプリ（suguhiku.exe）はダウンロードできません。Releases からダウンロードしてください。

### v1.1.1 で直したこと

v1.1.0 の不具合と、安全性を直した版です。新しい機能はありません。

| 分野 | 直したこと |
| --- | --- |
| **安定性** | 壊れたセッション・セットリスト・テーマのファイルを読み込んでも、アプリが落ちないように |
| | 長すぎる・おかしな音源ファイルを読み込んでも落ちないように(30分を超える音源は「対応範囲外」と表示) |
| **安全** | 中身の大きさをごまかした .gp ファイルで、パソコンの容量やメモリを大量に使われないように |
| | セットリストのファイルが、決まったフォルダの外に書き込まれないように |
| **保存** | 曲名の大文字・小文字だけを変えて保存すると、同じ曲のセッションが2つできてしまう不具合を修正 |

## 動かすのに必要なもの

- Windows 10 / 11（64 ビット）
- Microsoft Edge WebView2 ランタイム
  - Windows 11 には最初から入っています。Windows 10 でも、たいていは Edge と一緒に入っています。
  - タブ譜や YouTube が表示されないときは、[こちらのページ](https://developer.microsoft.com/microsoft-edge/webview2/)から「エバーグリーン ブートストラップ」を入れてください。
- ギターの音を出すには、オーディオインターフェース（ギターを挿す機器）
  - 無くても、音源の再生・タブ譜・メトロノームは使えます。

## インストール

1. ダウンロードした zip ファイルを右クリックし、「すべて展開」を選びます
2. 展開したフォルダを、好きな場所に置きます（例: ドキュメントやデスクトップ）
3. フォルダの中の「suguhiku.exe」をダブルクリックすると起動します
   - よく使う場合は、suguhiku.exe を右クリック →「スタートにピン留めする」などが便利です

> 初めて起動すると、「Windows によって PC が保護されました」と出ることがあります。
> 個人で作ったアプリで、電子署名が付いていないためです。
> 「詳細情報」を押し、「実行」を押すと起動します。

## 最初に1回: オーディオの設定

1. 一覧画面の右上の歯車（設定）を押します
2. いちばん下の「オーディオの入出力」で、お使いのオーディオインターフェースを選びます
   - 「Audio device type」で「ASIO」を選ぶと、ギターの音の遅れが小さくなります
   - 入力は、ギターを挿した入力だけを有効にしてください
3. 設定は自動で保存され、次から同じ設定で起動します

## できること

| | |
| --- | --- |
| **音源** | 手持ちの音楽ファイル（mp3 など）か、YouTube の動画。速度を変えても音程は変わりません |
| **タブ譜** | Guitar Pro（.gp など）・PDF・MusicXML。再生に合わせてカーソルが進み、PDF は画面が流れます。.gp は、タブ譜の音を鳴らしたり、その場で直したりもできます |
| **音色** | クリーン・歪み（内蔵）、NAM のモデル、VST プラグイン。プリセット 1・2・3 に覚えさせて、ボタンひとつで切り替え |
| **練習の道具** | 速度の変更、苦手な小節のループ、メトロノーム、チューナー |
| **セットリスト** | ライブの曲順をまとめて、1曲目から通しで再生 |

曲ごとの設定（音源・タブ譜・音色・速度・ループなど）は「セッション」として保存され、次に開くとそのまま戻ります。

## 使い方: 1曲を練習する流れ

例として、YouTube にある曲を、ネットで見つけたタブ譜（.gp）で練習するとします。

### 1. セッションを作る

1. 一覧画面の右下の「＋」を押します
2. 曲名を入れます（必要なのは曲名だけ。アーティスト・BPM などはあとからでも構いません）
3. 音源に YouTube の URL を貼り付け（または音楽ファイルを選び）、タブ譜のファイルを選んで、練習を始めます
   - .gp のタブ譜なら、曲名・アーティスト・BPM・チューニングを、タブ譜から自動で入れます
   - タブ譜にギターのトラックがいくつもあるときは、どれをリード・どれをバッキングにするか聞かれます

### 2. 音とタブ譜を合わせる

1. 練習画面の左にタブ譜、右に動画が出ます。「▶」（またはスペースキー）で再生すると、タブ譜のカーソルが曲に合わせて進みます。最初の「▶」は数秒のカウントダウンのあとに始まるので、その間にギターを構えます
2. 前奏があってタブ譜の1小節目とずれるときは、再生バーで1小節目が始まる位置を選び、タブ譜の上の「ここから流す」を押します
3. まだ少しずれるときは、右の「テンポとずらし」で細かく合わせます（BPM、「拍の位置」「タブ譜だけ」のずらし）

### 3. 音を作る

1. 右の「音色」で、クリーン・歪み・NAM・VST から選びます。VST は、持っているプラグイン（Neural DSP など）を選べ、「プラグインを開く」でタブ譜の場所に画面を出せます
2. 気に入った音は、下のプリセットの空いているボタン（1・2・3）を押して覚えさせます。リードとバッキングで別のプリセットを割り当てると、トラックを切り替えたときに音も変わります
3. 曲の途中で音を変えたいときは、再生バーを右クリック →「現在位置から音色を変える」で、その場所に切り替えを置けます
4. 音量は右の「ミキサー」で、音源・ギター・メトロノームを別々に調整します

### 4. 練習する

- **ゆっくり弾く**: 下の「速度」を下げます（50〜200%）。タブ譜とメトロノームも付いてきます
- **苦手な小節をくり返す**: 再生中に、くり返したいところの始めで「A」、終わりで「B」を押し、「繰り返す」をオンにします。A・B は小節の頭にそろいます
- **メトロノーム**: 「曲に合わせる」で、曲の拍に合わせて鳴ります。「単体」で、曲を止めたままメトロノームだけ鳴らせます
- **チューニング**: 右上の音叉のボタンでチューナーを開きます（開いている間は、ギターの音が自動でクリーンになります）
- **ギターを持ったまま操作する**: マウスの左右のボタンを同時に押し続ける（または真ん中のボタンを押し続ける）と、丸いメニューが出ます。再生・停止、ループ、ミュート、プリセットの切り替えなどを、マウスを動かして離すだけで選べます

### 5. 保存して、次の日に続きから

右上の保存のボタン（または Ctrl+S）で保存します。次の日は、アプリを起動して一覧から曲を開き、「▶」を押すだけで、前の日と同じ音・速度・ループで続きを始められます。起動した直後は一覧のいちばん上の曲が選ばれているので、Enter だけで開けます。

## ライブに向けて: セットリスト

1. 一覧画面の上の「セットリスト」を開き、右下の「＋」で新しいセットリストを作ります
2. 「＋ 曲を追加」で、練習したセッションを曲順に並べます（ドラッグで並べ替え）。「•••」のメニューから、名前やライブの日を入れられます
3. 「▶ 通しで再生」を押すと、1曲目が開きます。「▶」で弾き始めると、曲が終わるたびに次の曲が開いて、カウントダウンのあと自動で始まります。それぞれの曲の音色・設定も切り替わります
4. ライブが終わったら、「•••」→「ライブ終わった」で、そのセットリストは「過去のセトリ」として下にまとまります

## 知っておくと便利なこと

- **曲の一部だけを使う**: 再生バーを右クリック →「開始位置」「終了位置」で、音源のその間だけを再生します（セットリストでも、その範囲で次の曲へ進みます）
- **タブ譜を直す（.gp）**: タブ譜の数字をダブルクリックすると編集モードになり、数字キーでフレットを変えられます（音の追加・削除、右クリックで拍・小節の挿入、Ctrl+Z で元に戻す）。保存すると .gp のファイルに書き込みます（最初の1回は、元のファイルを「.gp.bak」として残します）
- **PDF のタブ譜**: 再生に合わせて画面が上から下へ流れます。速さはタブ譜の上のスライダーで調整し、PDF の上の右クリックで繰り返しの範囲を置けます
- **動画を大きく見る**: タブ譜の上の「動画と入れ替え」で、動画を左の大きな枠に出せます
- **キーボードで操作する**: 一覧画面は矢印キーと Enter だけでも操作できます。練習画面では、スペース（再生・停止）、← →（戻る・進む）、Home（頭へ）が使えます

## データの保存場所

| 内容                     | 場所                                                                                          |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| セッション・セットリスト | `ドキュメント\suguhiku`（v1.0 の `ドキュメント\GuitarPractice` は、起動したときに自動で名前が変わって引き継がれます） |
| 設定・動作の記録         | `%APPDATA%\GuitarPractice`（エクスプローラーのアドレス欄に `%APPDATA%` と入力すると開けます） |

## アンインストール

展開したフォルダを削除してください。
保存したセッションや設定も消したいときは、上の「データの保存場所」の2つのフォルダも削除してください。

## ご意見・不具合の報告

設定画面のいちばん上の「フィードバックを送る」ボタンから、フォームを開けます。
不具合のときは、設定の「動作ログ・クラッシュの記録を見る…」の内容を添えていただけると助かります。
