- 技術: C++20 / JUCE 8.0.15 / CMake / Windows のみ。タブ譜（alphaTab 1.8.4）と YouTube は WebView2 の中で動かす
- 作者: C++・JUCE は初めて。AI と作る過程を学ぶことも作品の目的。返事は日本語・やさしい言葉で

## 4. 作りの要点（詳しくは `コード解説.md`）

- **層**: `Model`（データ）・`Audio`（音）・`UI`（画面）・`Library`/`Setlist`/`Session`（一覧・セットリスト）・`Theme`（見た目）・`Web`（WebView）・`Platform`
- **オーディオスレッドの規約**: メモリ確保・ロック・ファイル操作をしない。値は `std::atomic`、大きなもの（音源・NAM・VST3）は別のスレッドで作ってポインタを差し替え、古いものは「引退リスト」に入れて UI スレッドで解放する
- **画面の切り替え**: `MainComponent::navigate()` で次のメッセージに回す。`showSession()` は前の画面を先に消す（8章）
- **WebView・VST3 の画面は Windows の別の窓** で、JUCE の部品より手前に描かれる。上に何かを出すときは WebView を隠す（`placeWebViews`）か、ページの中に出す（カウントダウン）か、枠のない別のウィンドウにする（メトロノームの大きな表示・ラジアルメニュー）
- **再生位置は1つ**: `SessionScreen::getPosition()`（ローカル音源 = エンジン、YouTube = ページ、**音源なし = `ScoreClock`**）。タブ譜の針・タブ譜の音（MIDI）・メトロノーム・ループ・曲の終わりは、すべてこの位置に付いてくる。タブ譜のページへは 0.1 秒ごとに「位置・BPM・ずらし・速度・再生中か」を送り、ページが針をなめらかに動かし、MIDI を合わせる（`syncMidi`。拍で合わせ、0.08 秒ずれたら合わせ直す）
- **タブ譜の小節は「演奏する順」**: 繰り返し記号・1番かっこ 2番かっこを展開した順（alphaTab の `MidiFileGenerator` の `tickLookup` から。MIDI と同じ）。`ScoreViewer::getBarStartBeats()` などの index は演奏順で、楽譜の小節の番号は `getBarNumber()`。ページの針は `barIndex` で楽譜の小節に置く（`コード解説.md` 38章）
- **タブ譜の音**: alphaTab のプレーヤー + SONiVOX の SoundFont（同梱、Apache 2.0）。鳴らすのはリード・バッキングのトラックだけ（`setMidiTracks`）。音は WebView から出る（アプリのミキサー・ASIO は通らない）
- **セッションの保存**: `ドキュメント\GuitarPractice\Sessions\*.gppractice`（JSON。`session_id`、`last_opened`、`score.lead_track`/`backing_track`/`active`/`lead_preset`/`backing_preset`、`tone_slots`（プリセット 1〜3）、`mixer.lead_tab`/`backing_tab` など。無い項目は既定値で読む）。「未保存」の判定は JSON の比べ合い（`savedSnapshot`）。トラックの切り替え・`last_opened`・曲の長さは、ほかに変更が無ければそのまま保存して「未保存」にしない
- **セットリスト**: 速度・ループはエントリ専用（`PlaybackSettingsResolver`）。通し再生ではループを外して開く。曲の終わり → カウントダウン（設定の「セットリストの待ち時間」）→ 次の曲の画面で数える
- **アイコン**: `svg icons/` の SVG を埋め込み、明るさで判断してテーマの色に塗り替える（`UI/Icons`）。大きさは SVG の viewBox で決める
- **ラジオボタン**: オフになったボタンにも `onClick` が来る。`onClick` では `getToggleState()` を確かめる
- **画面に依存しない計算は単体テストあり**: セットリスト・カウントダウン・再生ボタンの2回押し・並び替え（`SessionSort`）・リード/バッキングの決め方（`ScoreParts`）・`ScoreClock`・フォルダ・拍の位置（`MusicInfo`）・音程検出

## 8. 気をつけること（はまったところ）

- 画面の切り替えで、古い画面のデストラクタが新しい画面の読み込みを消すことがある（セットリストで起きた）。`showSession()` は古い画面を先に消す
- `MainComponent` のメンバーは宣言と逆順に消える。画面（`currentScreen`）は WebView を使って後片付けするので、デストラクタで最初に消す
- VST3: 編集画面はプラグインより先に、「編集画面 → ウィンドウ」の順で消す。プラグインは同時に1つだけ（Misha は2つ目があると落ちる）
- NAM は OBJECT ライブラリでリンクする（STATIC だとモデルの種類の登録が捨てられる）。IR の .wav は JUCE で書き直してから NAM に渡す
- **alphaTab 1.8.4 の不具合**: `api.midiLoaded` に登録すると、`loadedMidiInfo` が自分を呼び続けて「Maximum call stack size exceeded」で読み込みが止まる。登録しない（描き終わり・再生開始でトラックの設定を当て直す）
- SVG のアイコン: 形の座標は viewBox のまま読み込まれる（width・height ではない）。色は黒以外のこともある（歯車は `#292D32`）ので、明るさで塗り替える
- **テーマの切り替えと Font**: `juce::Font` は一度使った書体を中に覚える。部品が持っている Font（ラベル・入力欄）は、テーマを変えても前の書体のまま。`AppLookAndFeel::withoutCachedTypeface` で捨ててから使う（`コード解説.md` 37.1）
- JUCE のボタンは左右に余白を取るので、幅が狭いと文字が「…」になる（「>」は 24px 以上、歯車は 40px）
- YouTube は再生を始めるまで動画を読み込まない（カウントダウン中に音を消して一瞬再生して先読み）
- **落ちたときの調べ方**: `%LOCALAPPDATA%\CrashDumps\suguhiku.exe.*.dmp`（前の名前は `Guitar Practice.exe.*.dmp`）。WinDbg（導入済み）の `cdb.exe -z <dmp> -y <PDB のフォルダ>` に `.ecxr` と `kn`。イベントログ（Application の ID 1000）
- TONE3000 の音色は利用規約で同梱できない。プラグイン本体の同梱も許可を確認するまでしない
