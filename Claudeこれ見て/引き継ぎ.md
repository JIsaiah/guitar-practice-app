## 1. このアプリ

ギター練習用の Windows デスクトップアプリ。音源（ローカルファイル／YouTube）・タブ譜・音色（ギターの音作り）・メトロノーム・チューナーを1画面にまとめ、曲ごとの「セッション」として保存・復元する。

- **仕様の正**: `Claudeこれ見て/設計書_v0.7.md`。セットリストモードの仕様は `後で使う/setlist-mode.md`（フェーズ5・6が残っている）
- **作者の最新の要望・不具合**: `Claudeこれ見て/開発者用メモ`（作業のたびに確認する）
- 技術: C++20 / JUCE 8.0.15 / CMake / Windows のみ。タブ譜（alphaTab）と YouTube は WebView2 の中で動かす
- 作者: C++・JUCE は初めて。AI と作る過程を学ぶことも作品の目的

## 3. ビルドと開発用の道具

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Debug      # Release も警告 0 で通る
```

- JUCE・WebView2 SDK・ASIO SDK 2.3.4・NeuralAmpModelerCore v0.6.0（Eigen）は、初回の構成で自動取得（`BUILDING.md`）
- 自動テスト: `GuitarPracticeTests`（`Tests/`、ctest）。25件（セットリストまわり 17件、`MusicInfo`・詳細の保存 3件、チューナーの音程検出 1件、フォルダ分け 4件）
- 開発用（Debug のみ）:
  - `--render-logos <フォルダ>`: 画面・ロゴを PNG に書き出す（ウィンドウを開かない。作者の設定・セッションに触れない）
  - `--audio-check <フォルダ> [--nam <.nam>] [--ir <.wav>] [--plugin <.vst3>]`: デバイス一覧、NAM・VST3 の処理時間・状態の保存と復元・画面の大きさ
  - `--plugin-window-test <フォルダ> --plugin <.vst3> [--close-before-replace|--unload-first]`: プラグインの画面のウィンドウを開き → 閉じる → 開き直す → プラグインを差し替える（曲の切り替えと同じ）。各段階を `plugin-window.txt` に書く（画面に 30 秒ほどウィンドウが出る。落ちればログはそこで止まる）
- WebView の中身（タブ譜のページ）は、ページと alphaTab を一時フォルダに置き、`python -m http.server` と Edge のヘッドレスで確かめた

## 4. 作りの要点（詳しくは `コード解説.md`）

- **層**: `Model`（データ）・`Audio`（音）・`UI`（画面）・`Library`/`Setlist`/`Session`（セットリスト）・`Theme`（見た目）・`Web`（WebView）
- **オーディオスレッドの規約**（設計書 5.3）: メモリ確保・ロック・ファイル操作をしない。値は `std::atomic`、大きなもの（音源・NAM・VST3）は別のスレッドで作ってポインタを差し替え、古いものは「引退リスト」に入れて、コールバックが2回進んでから UI スレッドで解放する
- **画面の切り替え**: `MainComponent::navigate()` で次のメッセージに回す（ボタンの処理中に画面を消さない）
- **WebView・VST3 の画面は Windows の別の窓** で、JUCE の部品より手前に描かれる。重ねるパネル（チューナー等）を出すときは隠す
- **ラジオボタン**: オフになったボタンにも `onClick` が来る。`onClick` では `getToggleState()` を確かめる

## 8. 気をつけること（はまったところ）

- 画面の切り替えは「新しい画面を作る → 古い画面を消す」の順。古い画面のデストラクタが、新しい画面の登録や読み込みを消すことがある（セットリストで実際に起きた。`showSession()` で古い画面を先に消す）
- VST3 の編集画面はプラグインより先に消す。`createEditorAndMakeActive()` は既に画面があれば nullptr
- VST3 の後片付けは「編集画面 → ウィンドウ」の順（逆だとプラグインの窓が先に壊れる）。プラグインは同時に1つだけ持つ（Misha は2つ目があると落ちる）。`AudioEngine::loadPluginToneAsync` が古いものを消し終えてから作る
- **落ちたときの調べ方**: Windows が `%LOCALAPPDATA%\CrashDumps\Guitar Practice.exe.*.dmp` を残す。WinDbg（winget の `Microsoft.WinDbg`。作者の許可を得て導入済み）の `cdb.exe -z <dmp> -y <PDB のフォルダ>` に `.ecxr` と `kn` を渡すと、落ちた場所の呼び出しの流れが分かる。イベントログ（Application の ID 1000）にも、落ちたモジュール名が出る
- `MainComponent` のメンバーは宣言と逆順に消える。画面（`currentScreen`）は YouTube・タブ譜の WebView を使って後片付けするので、デストラクタで最初に消す
- NAM は OBJECT ライブラリでリンクする（STATIC だとモデルの種類の登録が捨てられる）。Debug でも NAM だけ最適化する
- IR の .wav は JUCE で読んで書き直してから NAM に渡す（NAM の WAV 読み込みは簡易）
- TONE3000 の音色は利用規約で同梱できない。プラグイン本体の同梱も許可を確認するまでしない
